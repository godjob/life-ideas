## 📅 週間計画と実績

1行が1週間（月曜〜日曜）。列の意味は次のとおり。

- **計画km**: その週に走る距離の**合計**（計画）。右の「実績km」と比べる
- **ロング走**: その週で**一番長く走る1本**。括弧内はペースの目安。レースの週はレースそのもの
- **ほかの練習・メモ**: ロング走とは**別の日**にやる練習と注意点。**ロング走の途中で本番ペースを走るという意味ではない**（ロング走は括弧内のゆっくりしたペースで通す）。「本番ペース10km」は、その時期に狙うレースのペース（奈良12/13 までは 5:32/km 前後、大阪2/28 までは 5:20/km 前後）で10km走る日を1回入れるという意味。書いていない日は 5〜8km のゆっくりジョグ
- **実績km・最長・登り**: 走行記録から自動で入る（その週の合計距離・一番長い1本・累積の登り）。終わった週には ✅ 計画の9割以上 / 🔶 6〜9割 / 🔻 6割未満 が付く。▶ は今週

### 毎週の型（④ウルトラ構築期）

| 曜日 | 内容 |
|------|------|
| 平日 2回 | 早朝ジョグ 5〜8km（いつもの5時台）。うち1回は坂道の上り下り（上りは歩き混ぜ、下りは細かいピッチ） |
| 平日 1回 | 補強15分（スクワット・ヒップリフト・カーフレイズ・つま先上げ）。走らない日でよい |
| 土曜 | ロング走（時間で管理。6:45〜7:15/km・心拍140前後・登りは歩く） |
| 日曜 | 連続ロングの2日目（疲れた脚で15〜20km）。家族の予定がある週は休み |

- ロング走は **早朝5時スタートで9〜10時に帰宅** を基本にし、土日の日中は家族の時間にする
- 連続ロングは「月2回まで」。回復週（4/5・4/26の週）は量を3割落とす
